# 企业 Agent 分配与分级管理

## 目标

将 Agent 的使用权与配置管理权分离，满足企业中“管理员预配置、员工使用、部门管理员治理”的权限模型。

## 验收标准

- 普通用户只能查看完整配置、编辑和删除自己创建的 Agent。
- 分配给普通用户的 Agent 在管理页只显示摘要，可以进入对话，但不返回完整配置。
- 绑定部门的 Agent 由该节点及其上级部门管理员管理，下级部门管理员不能修改上级统一 Agent。
- 仅指定用户的 Agent 由创建者当前主部门管理员管理，员工调岗后管理权随之变化。
- 全局 Agent 仅创建者和超级管理员管理；内置 Agent 不能删除。
- `manage_scope` 不再授予 Agent 管理权。
- 部门管理员修改分配时，范围外既有绑定保持不变。
- 所有写操作继续受 `agents.update/delete/share` 功能权限约束并记录操作日志。
