# 自定义角色权限矩阵

## 目标

在保留现有 `superadmin`、`admin`、`user` 默认行为的基础上，引入可持久化的全局自定义角色与“资源 × 动作”权限矩阵。权限决定用户能执行的动作，部门、创建者和 `share_config` 继续决定动作可作用的数据范围。

## 验收标准

- 超级管理员可创建、编辑和删除未被使用的自定义角色，并为用户分配单一角色。
- `superadmin` 始终拥有全部权限且不可编辑；`admin`、`user` 不可删除或改 key，但可调整权限。
- 登录和当前用户接口返回角色名称及权限列表，前端菜单、页签和按钮按权限展示。
- 后端所有管理能力以权限检查为最终边界，API Key 每次请求使用绑定用户的当前角色权限。
- 权限不能绕过部门、资源创建者或共享范围；按 ID 操作知识库时仍需通过资源级授权。
- 非法角色、未知权限、删除在用角色和越权操作返回明确的 4xx 响应。
